# Plans

Temporary task plans.

- `active/`: T3 plans (architecture, data format, protocol, public API, concurrency, security) awaiting or under the owner's confirmation.
- `archive/`: completed, cancelled, or superseded plans. Do not read by default.

Smaller work (T0-T2) plans in the reply, not in a file. `scripts/new-plan.sh <id>` creates a plan; `scripts/archive-plan.sh <plan>` archives it.
